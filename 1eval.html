UP1 · 11 sesiones Tema 3.1

Un lenguaje universal

Monomios y polinomios

Expresión algebraica: números y letras unidos por operaciones. Su valor numérico se obtiene sustituyendo las letras por números.

  • Monomios semejantes: misma parte literal. Solo esos se suman.
  • Polinomio: suma de monomios. Grado = el mayor grado de sus monomios.
  • Ordenado: de mayor a menor grado. Completo: tiene todos los grados.
  • Mónico: el coeficiente principal es 1. Término independiente: el de grado 0.

Identidades notables

(a + b)2 = a2 + 2ab + b2
(a − b)2 = a2 − 2ab + b2
(a + b)(a − b) = a2 − b2

Regla de Ruffini

Solo cuando el divisor es de la forma (x − a). Ejemplo: (3x3 + 4x2 − 8x) : (x + 3), aquí a = −3.

Teorema del resto y del factor

Teorema del restoEl resto de dividir P(x) entre (x − a) es P(a).
Teorema del factor(x − a) es factor de P(x) ⇔ P(a) = 0.
Entonces a es raíz de P(x).

Ejemplo: ¿es (x − 2) factor de P(x) = x3 + x2 − 7x + 4?   P(2) = 8 + 4 − 14 + 4 = 2 ≠ 0 → no es factor (y el resto vale 2).

Pista de las raíces enterasLas raíces enteras de un polinomio con coeficientes enteros son divisores del término independiente. Pruébalas con Ruffini.

Factorizar un polinomio

1. Sacar factor común.
2. ¿Es una identidad notable?
3. Ruffini con los divisores del término independiente, hasta llegar a grado 2.
4. Grado 2 → fórmula: ax2 + bx + c = a(x − x1)(x − x2)

Ejemplo: x4 − 2x3 − 11x2 + 12x + 36

1−2−111236

De nuevo x = 3 → queda x2 + 4x + 4 = (x + 2)2
→ (x − 3)2(x + 2)2

  • Irreducible: no se puede factorizar más (grado 1, o grado 2 con Δ < 0).
  • M.C.D.: factores comunes con el menor exponente. m.c.m.: comunes y no comunes con el mayor exponente.
  • Dos polinomios son primos entre sí si no tienen ningún factor en común.

La igualdad es la clave

Identidad: igualdad que se cumple siempre, como (x + 1)2 = x2 + 2x + 1. Ecuación: solo se cumple para algunos valores, las soluciones.

Ecuaciones de 2º grado

ax2 + bx + c = 0
x = −b ± b2 − 4ac2a
Δ = b2 − 4ac (discriminante)
Δ > 0 → dos soluciones
Δ = 0 → una solución (doble)
Δ < 0 → sin solución real
Incompletas, sin fórmulab = 0: ax2 + c = 0 → x = ±−c/a
c = 0: x(ax + b) = 0 → x = 0 ó x = −b/a
¡Nunca dividas entre x!En 5x2 = 15x, si divides entre x pierdes la solución x = 0. Saca factor común.

Bicuadradas y grado ≥ 3

Bicuadrada ax4 + bx2 + c = 0 → cambio t = x2

x4 − 15x2 − 16 = 0 → t2 − 15t − 16 = 0

t = 15 ± 172 → t = 16 → x = ±4 · t = −1 → no hay x

Solución: x = 4, x = −4

Grado ≥ 3: pasar todo a un lado, factorizar e igualar cada factor a 0.

x3 − 5x2 + 6x = 0

x(x − 2)(x − 3) = 0 → x = 0, 2, 3

grado n → como mucho n soluciones

1. Aísla la raíz en un miembro.
2. Eleva al cuadrado los dos miembros enteros.
3. Resuelve.
4. Comprueba siempre: al elevar aparecen soluciones falsas.

No me da igual

Desigualdades

  • Sumar o restar el mismo número a los dos lados: la desigualdad se mantiene.
  • Multiplicar o dividir por un número positivo: se mantiene.
  • Multiplicar o dividir por un número negativo: cambia de sentido.
¡OJO!

2 < 3 ·(−1) → −2 > −3

Una inecuación es una desigualdad con incógnitas. Sus soluciones suelen ser intervalos o semirrectas: infinitos números.

Inecuaciones de 1er grado

3(x − 5) − 5 > 5(x + 1) − 1

3x − 20 > 5x + 4

−2x > 24 → x < −12 ÷(−2): ¡cambia!

Solución: (−∞, −12)

Inecuaciones polinómicas (grado ≥ 2)

1. Todo a un lado: P(x) ≥ 0.
2. Factorizar (raíces).
3. Tabla de signos de cada factor.
4. Escoger los intervalos con el signo pedido. Las raíces van con [ ] si hay ≤ ó ≥.

x3 + 4x2 + x − 6 ≥ 0 → (x − 1)(x + 2)(x + 3) ≥ 0

(−∞,−3)(−3,−2)(−2,1)(1,+∞)
x + 3−+++
x + 2−−++
x − 1−−−+
producto−+−+

Solución: [−3, −2] ∪ [1, +∞)

Casos especialesx2 + 2 > 0 → se cumple siempre: ℝ
x2 + 2 < 0 → nunca: sin solución

Inecuaciones racionales

x − 4x + 5 > 0

Tabla de signos con numerador y denominador:

(−∞,−5)(−5,4)(4,+∞)
x − 4−−+
x + 5−++
cociente+−+

Solución: (−∞, −5) ∪ (4, +∞)

¡NO SE HACE!

no se multiplica por el denominador: no sabemos su signo

las raíces del denominador van siempre abiertas (no se puede dividir entre 0)

Con valor absoluto

|x − a| < r ⇔ a − r < x < a + r
«a menos de r de a» → un intervalo
|x − a| > r ⇔ x < a − r ó x > a + r
«lejos de a» → dos semirrectas

|2x − 6| > 10 → 2x − 6 > 10 → x > 8 · 2x − 6 < −10 → x < −2 → (−∞, −2) ∪ (8, +∞)

Sistemas de inecuaciones con una incógnita

Se resuelve cada una por separado y la solución es la intersección: lo que se cumple en las dos.

8x − 4 > 7x − 2 ≤ 18 → x > 11/8x ≤ 20 → (118, 20]

Inecuaciones con dos incógnitas

Su solución es un semiplano. Pasos para 2x + 3y > 8:

  • Dibuja la recta frontera 2x + 3y = 8: pasa por (4, 0) y (1, 2).
  • Línea discontinua si es < ó >; continua si es ≤ ó ≥.
  • Prueba un punto, como (0, 0): 0 > 8 es falso → la solución es el semiplano que no contiene el origen.

Sistemas: la solución es la zona común a todos los semiplanos.
